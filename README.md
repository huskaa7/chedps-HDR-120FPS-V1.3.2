📌 About

Chedps HDR+120FPS is an Android gaming optimization project developed by Chedps. Its goal is to improve PUBG Mobile graphics quality, provide high-frame-rate configuration options, and optimize the gaming experience on compatible Android devices.

🚀 Features

- HDR graphics configuration.
- High FPS configuration (up to 120 FPS where supported).
- iPad-style viewing experience.
- Gaming performance optimization.
- Device-specific compatibility support.
- Smooth gameplay configuration.
- Root-based customization.

📱 Compatibility

- Android devices.
- Root access may be required for certain features.
- Device and game-version compatibility may vary.
- 120 FPS requires compatible hardware, display, kernel and game support.

🎮 Supported Games

- PUBG Mobile Global
- PUBG Mobile Korea
- Other supported PUBG Mobile versions (depending on configuration).

⚙️ Requirements

- Android device.
- Root access for root-dependent features.
- Compatible PUBG Mobile version.
- Supported graphics and refresh-rate capabilities.
